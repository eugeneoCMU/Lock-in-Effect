# Figures

Publication figures for the lock-in paper, generated entirely from committed
result artifacts — no recovery share, dollar figure, or correlation is
hardcoded in the generators (enforced by tools/liveness_gates.py).
Regenerate with:

```bash
python3 figures/make_ccf_data.py   # rebuilds ccf_data.json (gated)
python3 figures/make_figures.py    # all figures, or pass fig1 fig2 …
```

Style: Okabe-Ito colorblind-safe palette; paradigms are color-coded throughout
(vermillion = household choice / ABM, blue = loan-level survival / hazard,
purple = cross-design hybrids).

## `ccf_data.json`

±6-lag cross-correlations regenerated by the committed, gated
`make_ccf_data.py` (stored result JSONs only cover ±3; the overlapping
values are gated to match them exactly):

- ABM: `abm/data/runs/run-2026-07-04-15yr-foldin/metrics_monthly.csv`
  (`Empirical_CPR_Pct` vs `US_CPR_Pct`) — the **production** run the
  manuscript's Table 2 quotes (lag-0 r −0.318). Earlier editions of this
  file used the `run-2026-07-05-berger` variant series.
- Path A / Path B: `hazard/data/simulation_results.parquet` (spec v4,
  hash-identical to the frozen `run-2026-07-14-pathA-seasonal` artifact) /
  `hazard/data/microsim_results.parquet` against the hazard scorer's own
  empirical series (`macro.build_empirical_metrics`), 42-month QT window,
  `cpr_cross_correlation(max_lag=6)`

Sign convention (corrected in the v15 referee round, [TECHNICAL.md §22.3b](../TECHNICAL.md#22-manuscript-verification-record-referee-rounds-july-2026)): a peak at negative lag means the **empirical series leads and the simulated path trails** under the implemented `cpr_cross_correlation` convention.
