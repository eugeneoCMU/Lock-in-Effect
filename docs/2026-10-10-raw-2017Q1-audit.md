# Freddie 2017Q1 source audit

The one-quarter audit completed October 10, 2026, under the specification frozen
before raw access. Both the legacy unordered production calculation and the
repaired chronological calculation agree with the independently implemented
chronological reference within the prespecified tolerance. This quarter shows
no measured payoff-numerator change from the ordering repair. That result does
not establish the integrity of the other nineteen acquisition quarters or
validate the legacy aggregate panel and its calibration.

## Scope and checks

Only `orig_2017Q1.txt` and `perf_2017Q1.txt` were accessed. The first attempt
timed out before reading rows because the main Drive app was not running.
Starting Drive and requesting the same pair resolved access. The first error
report is preserved. No other quarter was downloaded or processed.

The raw schema gate precedes outcome processing. Every origination and
performance record has the expected 32 fields, the identity/date positions
pass, no origination ID is duplicated, and every performance ID matches an
origination ID. Both exact source-byte hashes were checked again after the
replays and are unchanged. The parser skips any performance row after
September 2025 before converting outcome values. There were no later-month
rows in this source pair.

- Origination records: **290,601**; eligible fixed-rate loans: **290,558**.
  Of these eligible loans, **217,530** have an original 360-month term.
  Production eligibility is not a 30-year-only restriction.
- Performance records: **16,516,599**; eligible loan-months: **16,513,080**.
- Independent aggregate reference: **4,847 cohort-months**.
- No duplicate loan-months, backward within-loan records, group re-entries,
  missing/nonfinite ages, or invalid/negative balances in eligible histories.
- **63 missing calendar months** across eligible histories. No voluntary
  payoff has a nonadjacent observed prior balance.
- **216,031** voluntary payoff records, including **139 first-observed
  payoffs**. Their original-principal fallback sums to **$33.659 million**.
  That is an imputed numerator contribution, not independently observed
  preceding principal.

## Independent reference and production replays

The reference sorts each contiguous loan history by reporting month and
aggregates the existing vintage/coupon/FICO/LTV/month cells. Both production
replays run separately with the same cutoff, frozen ingestion source, and two
processing threads. The legacy replay removes only the explicit ordering from
the lag. All 4,847 keys, counts, and mean ages agree. Balances, original-principal
sums, and payoff sums agree within relative tolerance 1e-10 and absolute
tolerance $0.00001. Floating-point summation order accounts for residual
differences; the largest payoff-cell difference is about $0.00000131.
The legacy replay uses the current frozen execution environment; it does not
recover the original historical twenty-quarter join ordering.

The reference records $45.06925626432 billion of cumulative payoff principal,
including the fallback, and $3,099.294467879 billion dollar-months of end
exposure. These quantities have different time units and must not be described
as a portfolio balance or an observed monthly opening-risk probability.

Fixed replay took 19.3 seconds and reached approximately 2.83 GiB observed RSS;
legacy replay took 16.3 seconds and reached approximately 3.03 GiB. Neither
reached the 8 GiB memory or 12 GiB free-space stopping threshold. The streaming
audit's peak memory was about 101 MiB. No source or production input was replaced.

## Interpretation and retained evidence

A successful replay of one already ordered quarter is consistent with a real
ordering defect that manifests on differently ordered inputs. Synthetic tests
demonstrate the defect; this pilot does not demonstrate its magnitude in the
saved full panel. It also retains first-observation fallback by design, so
agreement between implementations does not validate that missing balance.
The full rebuild still needs source checks across all quarters, cross-file
membership reconciliation, an explicit opening risk set, and dependent
calibration/prediction/simulation reruns.
